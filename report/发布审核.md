## 明确保留的复现限制

1. 历史 `trace_msa_recycling.py` 的命令快照含绝对路径，在更换目录后可报 `Trace plan changed`。不将该历史执行脚本承诺为便捷的跨目录分析入口，预测重跑需重建环境/权重/新方案。
2. `analyze_docking_benchmark.py`会更新所选目录的摘要；它不是只读审计，复算应使用副本。
3. 冻结MD执行器检查原GROMACS二进制哈希，用于原平台续跑。其他平台应另立实验协议，不能宣称原样跨平台续跑。
4. `config/environment.yml`包含macOS构建号；Ubuntu依赖以实际执行环境清单为准。未承诺一个安装文件覆盖所有平台。
5. 当前数据仅单一对接体系和短肽。四格每格三个种子、短长分支共享历史，两个起点溶剂准备不同；不作收敛、纯构象因果或真实折叠机制推断。

## 发布验收

GitHub Actions对实际提交执行只读轻量核验；固定版本及附件以Release页面为准。原始数据包下载后须检查SHA-256，再在独立checkout解压。具体操作见仓库根目录 `REPRODUCING.md`。
