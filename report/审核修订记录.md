# 审核修订与验证记录

日期：2026-11-10。历史基线：`30f903f714b1ba2946da9d61f20301210d864acb`。本次修订以本地代码和产物为准，尚未推送或发布 GitHub Release。

## 修复

1. ColabFold 分开 `prepare_weights`（首次联网准备）、`analyze`（分析保存结果）、`predict`（新目录实际推理）；已有目录一律拒绝，避免完成标记造成静默跳过。
2. MD 每次重新处理所有分段，避免旧 `_fit.xtc` 混入；时间轴以整数 ps 核验，窗口统一为半开、末窗包含末帧，RMSF 与其他指标使用相同帧范围，并显式按 Cα 拟合。
3. 预测分析显式指定 ESMFold 输入标度，验证序列、Cα 完整性、pLDDT/PAE 维度与数值；多模型结果分别输出。PAE 坐标为 1–20，行 i 是对齐残基，列 j 是被评分残基，对应 AlphaFold 损失函数的 frame/point 定义。
4. 补充短肽 pTM 长度效应；准确说明官方教程准备输入、公开仓库与本地大文件的区别，不把平台化或预测置信度当成机制证据。
