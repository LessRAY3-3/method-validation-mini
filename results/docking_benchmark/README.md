# 配对种子重对接强化实验（待完成）

## 问题与预定设计

在完全相同的 1IEP 受体、配体、盒子和评分函数下，增加搜索强度是否提高找回晶体姿势的比例？

- 最小设计：exhaustiveness = 1、8、32，各用同一组 5 个种子（42、2026、20261110、20261111、20261112），共 15 次**新增**计算。
- 每次 `cpu=1`、`num_modes=9`、`energy_range=3 kcal/mol`。固定的完整输入校验和、参数、终点和限制已在首次计算前写入 `protocol.json`。
- 主终点：最优打分姿势的对称性校正重原子 RMSD ≤ 2 Å。保持受体坐标系，不做配体独立居中或叠合。
- 次终点：至少一个**已保存**姿势 RMSD ≤ 2 Å；另报告最接近晶体姿势的名次。这不能代表所有搜索过的构象，因为输出有能量窗口过滤。
- 原子映射：spyrmsd 分子图对称性校正，并对所有姿势用 RDKit 图同构枚举 + NumPy 独立重算。
- 补充几何分析：受体残基与配体任意重原子距离 ≤ 4 Å 计为接触，报告相对共晶的接触召回率、精确率和 Jaccard。接触恢复不保证方向正确，也不代表特定氢键、亲和力或药效。

## 解释与验收

- 每组 n=5，成功比例附 Wilson 95% 区间，仅描述种子采样不确定性；不能衡量不同靶点、受体准备或质子化的不确定性。
- 配对种子并不代表不同强度下完全相同的随机搜索路径；它只使种子选择一致。
- 保留低分高 RMSD、主终点失败及次终点失败；比较搜到近晶体姿势却未排名第一的情况。
- 全部输入/输出哈希、15 项运行状态、原子数/分子图、全部姿势独立 RMSD 复核必须通过。
- 若 15 次都成功或强度差异不明显，如实报告这个容易恢复的共晶体系上的结果，不事后换体系求显著性。
